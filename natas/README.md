# Natas — Web Exploitation

OverTheWire's Natas wargame teaches server-side web security fundamentals.
Full writeups available at the [Techno-Lab documentation site](/overthewire/natas).

## Completed Levels

| Level | Technique |
|-------|-----------|
| 0 | HTML Source Review |
| 1 | Input Restriction Bypass |
| 2 | Directory Traversal |
| 3 | Robots.txt Enumeration |
| 4 | Referer Header Spoofing |
| 5 | Cookie Manipulation |
| 6 | Source Code Disclosure |
| 7 | Local File Inclusion |
| 8 | Encoded Secret Reversal |
| 9 | Command Injection |
| 10 | Input Filter Bypass |
| 11 | XOR Cryptanalysis |

See the [detailed documentation](/overthewire/natas) for walkthroughs.

## Usage

```bash
npm run dev      # Start development server (localhost:3000)
npm run build    # Build static site to out/
```
